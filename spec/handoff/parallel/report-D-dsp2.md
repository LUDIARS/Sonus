## 統合時に照合する契約の追記事項

#### D-217 追加項（8）・（9）　微小信号の相関と長時間の入力位置

（8）D-209 と D-217（2）の相関スコアは、有限で非零の候補エネルギー E のすべてについて、チャンネル別に合算した C と E から倍精度で C·abs(C)/E を求める。E=0 のときは 0。従来の実装が使った 1e−30 の閾値を廃止する。

（9）D-209 の「32.32 の固定小数点」の原点は保持履歴の始点とする。入力消費数は符号なし 64 ビットで数え、呼び出しの末尾で名目位置と切り出し位置の原点を整数フレーム分だけ進める。小数部 32 ビットの精度を保ち、更新は定数時間。通算 2^32 入力フレームの境界でも必要入力数・消費位置・出力が連続し、Init / Reset でのみ初期化する。

D-209 と上記「テストと測定」の所要時間に対する再測定値は、GCC 14.2 Release、x86-64、実装 bddce81、ステレオ 256 フレームで、速度 1 / 0.8 / 1.3 / 2.5 の順に 4.15 / 6.78 / 8.48 / 21.37 µs（入力の写しを含む）。公開 API で 4,296,016,896 入力フレームまで進め、2^32 の前後の PCM と消費位置、境界後の半フレーム単位のキャリーと Reset を検査した。

#### D-218 追加項（5）〜（7）　固定長の IR 切替と状態の大きさ

（5）D-218（1）の「周期の残り B−f を使う」規則と「次の呼び出しまで待つ」規則には、本項を優先する。活動中に新たな IR、登録解除、B・レートの不一致または IR なしを観測したフレームから、遅延 0・遅延 B のどちらでも固定 B フレームを線形補間する。j=0..B−1 で新側の重み g=(j+1)/B、出力は (1−g)×旧側 + g×新側。双方とも同じ入力履歴の畳み込みで、最終サンプルは新側の出力そのもの。休止中は即時に採用する。フェード中の要求は最新のものを保持し、進行中の B フレームを完走した直後のサンプルから適用する。公開呼び出し・max_frames の境界に依存しない。D-218（1）の「古い側は切り替えの前に既に計算してあった出力だけ」「2 組の写し」「FDL の積和を 1 回余分に回す」「負荷 270〜430 µs」と、理由欄の「両立しないので周期の残りで終える」「Defect_ のテストは失敗のまま」も、本項と（6）（7）で置き換える。IrSlot の選択には D-218（2）の呼び出し全体の終端値を使う。

（6）D-213 の「直接形の先頭のタップだけは状態に写す」と D-214 の状態式を更新する。切替前に次周期の既知入力による遠い分割の寄与を計算し、近い分割の係数を状態へ写す。フェード先も途中で解除され得るので、採用時にはさらに一周期先の寄与を準備する。新たな入力が届いたら保存した係数で残りを求め、切替を観測した後は旧 IR のメモリを読まない。C をチャンネル数、R を C²≤16 のとき C²、それ以外は C とすると、状態は FDL の 8×C×cap×B バイト、タップの写し 5×R×B×4 バイト、O(C×B) の出力・履歴・予測と作業領域、FFT プランから成る。補助領域を含めて 1 GiB 以内に収める。48 kHz、2 秒ステレオでは B=256 で 1,581,632 バイト（旧方式比 +18,432）、B=512 で 1,630,784 バイト。

#### D-219 追加項（5）・（6）　有界な登録枠の探索と番号の寿命

（5）D-219（1）のカーソルと一巡の説明には本項を優先する。登録ごとに共有カーソルから開始位置を取り、呼び出しごとに連続する 1024 枠を最大一度ずつ試す。競合する登録で走査位置が飛ぶことはなく、走査中を通じて空いている唯一の枠も調べる。各枠の論理番号は前回より先へ進み、下位 24 ビットを公開する。番号 0 は予約値で、枠 0 の候補番号が 0 になると同じ枠の次世代を使う。使用中の枠や満杯の登録試行もカーソル・候補番号の進みに影響し、「成功した登録が 2^24−1 回」で一巡する保証はない。

（6）D-219（1）の旧番号の無効化が成り立つのは、同じ完全な番号が再発行されるまで。番号の下位 10 ビットが枠、上位 14 ビットが世代で、枠 0 の世代は 16383 通り、他の枠は 16384 通り。解除には登録時の完全な番号を使い、パラメータ、保留中の要求、保存値を含めて旧番号を廃棄する。一巡後に同じ番号が発行されると、旧番号も新しい IR を解決・解除しうる。読みは「番号 → IR → 番号」の順で検証する。IR のメモリを解放できるのは登録を解除し、その IR を使いうる各システムで解除後に開始した描画が一回以上完了した後である。 D-219（2）の寿命の文は本項で読み替える。番号が一巡しうるので、「その IR を使いうるシステム」には古い番号の控えを持ちうるシステムを含む。控えの廃棄を保証できないときは、プロセス内の全システムで登録解除後に始まった描画が各 1 回以上完了するのを待つ。依頼 D-11 の core 側の条件として、バンクを外すときは IrSlot を 0 に戻し、番号をスナップショットに保存・復元しない。この配線は未実装。
