# 組③ 実装担当への依頼

作業先は `wip/b-g3`。着手前に `brief-common.md` の指定文書と B-handoff §5.2 を読み、設計書 §4.3・4.6 と `stage3-coverage.md` §2③・§3 を照合する。組②の D-130・D-131、組④のアクション時刻の扱いとの互換性を確認する。決定候補は D-160〜169。受け入れ側が採番する。

| 機能 | 作る経路と検査 |
| --- | --- |
| Parameter のスコープ・追従 | `PARM.scopeMask` の bit 0/1/2 を Global/Emitter/Playback に対応させる。許可された値を Playback → Emitter → Global → 既定値の順で解決する。不許可の書き込みで既存値や許可された下位スコープを隠さない。未定義の慣習名と従来バンク（省略値 7）を区別する。初回・途中の再指定・複数の再生で単位/秒の追従を確認する。 |
| 多点カーブと合成 | 3 点以上、端点・範囲外の頭打ち、区間ごとの shape を確認する。`CURV.compose` の有無と値の意味を bank-format および旧バンクの既定動作と照合する。同じ対象への寄与は音量 dB 加算・ピッチ cents 加算・LP 最小・HP 最大・その他は乗算。既存パンの期待との整合、単位・中立値・省略列と明示値の区別を報告する。Spread・ReverbSend・Blend3D は組①の最終レンダー入力につなぐ。Send / EffectParam カーブには宛先行の列が必要。推測で別の行を動かさず B-2 依頼に材料を出す。 |
| 重み付きスナップショット | `SNPV.targetKind` の 0（バス）、1（EFFX 行・paramIndex）、2（SEND 行）の全経路。複数スナップショットの同時寄与、フェード途中の再指定・解除で基準値へ戻ること、無効行・バンク解除を確認する。エフェクトの寄与は `fx_control.cpp` の D-130 の経路に入れ、公開 API のベース値、範囲制限、初期化時のみのパラメータを尊重する。プリ／ポストフェーダー両方の送出結果を見る。 |
| 時間付きアクション | ApplySnapshot の予約が親再生のトラック時刻で一度だけ効き、重みが指定時間で遷移するようにする。開始時刻と遷移時間は別の値。`ACTN.timeMs` と `ACTN.value` はそれぞれ時刻と値のまま使用する。現行形式に遷移時間の列が無いので、実行時の設定経路と、バンク入力・buildtool のための依頼を区別して報告する。組④の一時停止・拒否・停止の決定を引き継ぐ。 |
| ダッキング | kind 0 は入力バスのレベルに応じて対象を連続的に減衰させる。しきい値以下と異なる 2 つの超過レベル、量の上限、無音への復帰、attack / release を出力レベルと時間で検査する。kind 1 は指定カテゴリの発音中だけ効かせ、最後の発音の終了から解放を確認する。組②のコンプレッサーのキー入力と従来の DUCK の経路を両立させる。 |
| カテゴリ | 音量・ミュート・ポーズ（Playback、カテゴリ、全体）・ソロを確認する。ソロは公開 C API と C++ ラッパーから `SetCategoryVolume.reserved = 1` を通し、親子・複数ソロ・解除・バンク再登録の意味を明記する。`kCategoryIgnorePause` と `kEventIgnorePause` を個別に検査する。`SND_FOCUS_PER_CATEGORY` の喪失・復帰時、core では `kCategoryMuteOnFocusLoss` の対象だけゲインを変える。api の既存フォーカス処理への接続と既存仕様との食い違いは B-3 に依頼する。 |

予約欄は共通依頼 §2 の組③の割り当ての範囲で、必要なものだけ使う。未定義 variant、古い設定、範囲外の対象、再登録、満杯時の部分適用を検査する。既存のアサーション・凍結ファイル・バンク形式には触れない。組①・④と同じ関数を変えた場合は、最終合流で両経路を確認できるよう報告に関数名とテスト名を残す。

実装担当は自分の機能テストを core/test に足し、独立テストは別セッションに渡す。通常構成と clang Debug の警告、ASan/UBSan、TSan、Release、MinGW は共通依頼と B-handoff §3 に従う。直列 2 回と RT ワーカー 2 の一致、初期化後の確保 0、RT 違反 0、全経路を有効にした 128 実ボイスの Release 性能を数値で報告する。結果と未確認項目は `spec/handoff/parallel/B/report-g3-impl.md` に記す。
