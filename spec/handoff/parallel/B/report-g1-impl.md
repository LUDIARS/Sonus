# 組① 公開先頭から復元した実装

基点は公開済みの独立検査事前計画 `7aea75c`。統合先 `c86901f` の指示書を取り込み、形・ゾーンの契約と配線 `5f4748c`、空間化と描画 `67beaaa`、負荷・決定論セルフ試験 `488367c`、ゾーン解除ランプ `e5147d1` を作成した。

| 決定案 | 効果と根拠 |
| --- | --- |
| D-150 | 音速343 m/s、係数1が既定。リスナーから音源への単位ベクトル n に対して比は (c + factor・vL·n) / (c + factor・vS·n)。各項を音速の1%で下限とし、最終比を0.25〜4に制限する。距離ゼロ、係数ゼロで1。Pitchの既存ランプと上限を通す。 |
| D-151 | 音量カーブはdB、未設定時は最大距離打切り付き逆距離。距離入力のHPは既存の最大値合成。新しいロールオフ列は不要。 |
| D-152 | コーンの内外角は全角。blend 0で距離・コーン・ドップラー・距離LPを無効化。ゲインとパン行列は線形、ピッチとLP Hzは対数補間。 |
| D-153 | Nearestは最短距離、Weightedは正の重み、Splitは等重み。単独リスナーなら同じ経路。各リスナーのゲイン付きパン行列の加重平均。寄与（重み×振幅）が最大のリスナーの距離・LP・ドップラーを使う。同じ寄与なら先の番号、正の重みが無いときは有効リスナーを等分。出力・ピッチ・フィルターは既存のランプに乗せる。 |
| D-154 | 遮蔽を0〜−12 dB、LP 20 kHz〜1 kHz、閉塞を0〜−18 dB、LP 20 kHz〜800 Hzに写す。音量はdB、カットオフは対数で補間。遮蔽ゲインは共通、経路別LPはボイスFX後に処理し、直達では遮蔽と閉塞の低い側、送りでは遮蔽のみを適用する。閉塞ゲインは直達のみ。停止サンプル以降を経路のフィルター処理後にも切る。 |
| D-155 | 線は局所X、矩形はXZ、箱はXYZ。Emitter.forwardでZ軸を定める。最近点から測り、最大半寸法 r に対し形によるspreadを r/(r+d) として距離カーブと大きい側を取る。点はこの項が0。 |
| D-156 | EVNT.curveReverbSend は線形0〜1、当該EventのBUSSの最初のSEND行の宛先。元のバス送りと独立。音源・ボイスFX・共通フェーダーから取得し、宛先のチャンネル構成に空間化する。 |
| D-157 | ゾーンには形とバスID、線形量、フェード距離を指定。リスナーから形までの距離で線形フェードし、正の寄与上位4ゾーンを選ぶ。同率時はEmitterスロット順。同一バスの距離送りとゾーン送りを加算し1で頭打ち。ゼロ距離のフェードは形の内側のみ。解除した送りは元のバス世代が生きている間、1ブロックで0まで落とす。 |

## 契約と持ち場外への依頼

- 公開 C / C++ の SetEmitterShape、SetReverbZone は core::System に配線。snd_config 末尾に doppler_factor（0〜16）、speed_of_sound（1〜100000 m/s）。既存構造体サイズの受理・末尾詰め物は API 担当 B-3。
- SetParam の Emitter variant 2 は形状種別と半寸法（value=X、param=Yのfloatビット、reserved2=Zのfloatビット）、variant 3 はゾーン量と距離。SetSwitch の Emitter variant 2 はバスID。ゾーン設定2命令は一括の空き容量確認を行い、解除はバスID 0のSetSwitch 1命令。記録再生・LiveLink の検査は B-1。
- Emitter に shapeKind、halfExtents、zoneBus、zoneAmount、zoneFade、Spatial に shapeSpread、azimuth、coneAngle。列の書き手はそれぞれ ApplyCommands と Compute3D。契約版は1.2。
- Event 専用のリバーブ送り先、コーン外側の LP はbank/buildtoolに列が必要。距離音量カーブで線形・対数の減衰は表現できる。Splitの物理出力分離はplatform/api。空間化プラグイン用の方位・仰角・距離・spreadはB-5。
- 実装前の速度指定は既存の `indep_g2_kinds_test.cpp` にある。係数1の場合の決定論は同じ速度を与えた台本同士で比較する。

## 実装担当の検証

`CoreG1.MovingShapesAndFourZonesReplayBitExactly` は18移動音源の直列2回・RTワーカー2本の波形、レンダー後の確保とRT違反を検査する。`CoreG1.Split128MovingSourcesWithFourZonesWithinBudget` はSplit 2リスナー・128実声・4ゾーンの毎ブロックの移動を入力し、120ブロックのレンダーCPUを測る。実測待ち。組④との有限ループ試験は④取り込み後に実施する。

距離送りとゾーン送りでは、リスナーごとの送量を同じバス宛てで1まで合計し、各席の定位行列と寄与率を掛けてから合成する。一方の席だけがゾーン内なら、その席が聞く方向のみに送る。
