    - 既存の登録表（エフェクトの表）

## 1. 目的

設計書 15.1 の段階3 を完了させる。完了条件は、**設計書 7 章の表の全行に、設定意図どおりに振る舞うことを確かめる機能テストがあること**。

## 2. 範囲（作ってから、テストする）

まず 7 章の表を、行ごとに次の 3 つに分ける。分けた結果は `spec/interface/acceptance/stage3-coverage.md` に表で残す。
- 実装済み
- 一部だけ
- 未実装

そのうえで、足りないものを全部作る。主なものは次のとおり。

- **3D（4.5）**
  - 距離減衰（カーブ）
  - ドップラー
  - コーン
  - spread
  - 距離カーブ（音量、フィルタ、リバーブへの送り）
  - 範囲音源（形を持つ音源）
  - リバーブゾーン
  - ルーム／ポータルは段階6 なので、ここでは作らない。
- **標準 DSP 一式（7 章の「エフェクト」の行）**: CRI と Unity の和集合を作る。
  - リバーブ（I3DL2 を含む）
  - エコー、ディレイ
  - コーラス、フランジャー
  - ディストーション
  - コンプレッサー、リミッター
  - ノーマライズ
  - パラメトリック EQ
  - 各種フィルタ
  - ピッチシフター
  - サラウンダー
  - 音質を一致させることは目標にしない。
  - ボイスエフェクト: ローパスとハイパスは全ボイスに標準で付ける。重いものは DSP プールの枠で動かす。
- **Parameter（4.3）**
  - 3 つのスコープ
  - 多点カーブ
  - 追従速度
  - 合成の規則
- **スナップショット**: 重み付きで重ねがけする。
- **ダッキング**: サイドチェーンと、ルール型。
- **カテゴリ（4.6）**
  - ポーズ（Playback・カテゴリ・全体）
  - ポーズを無視するカテゴリ
- **ボイス管理の全機能（4.4）**
  - ボイスリミットのグループ
  - プライオリティ
  - 仮想ボイス
  - 奪い方の規則
- **解析**
  - バスごとのメーター、スペクトル、ラウドネス
- **シーケンス種別（4.2）**
  - ランダム、シャッフル、順送り、コンボ
  - Clip 単位のランダム幅
  - スイッチ型 Event
  - アクショントラック
  - 入れ子の Event
  - レイヤーのクロスフェード
- **再生中の通知**: 終了、マーカー、拍。

3 つのセッションに分ける行:
- music の行（時間制御）は、もう統合されている。B はテストを足すだけにする。
- 物理の行は A、拡張（Granular、Patch、タイムストレッチ）の行は D が受け持つ。

バンク形式・buildtool・ライブリンクの変更が要るものは、B の持ち場の外になる。`requests/B-*.md` に依頼を書く。そのあいだは、テストの中でバンクを組み立てるか、公開 API で設定する形で進める。

## 3. 進め方の目安

1 つの組が大きすぎないように、次の 4 組に分けて、組ごとに「実装 → 独立テスト → 受け入れ」を回す。ビルドする組は同時に 2 つまでにする。

1. 3D と距離カーブ
2. 標準 DSP とボイスエフェクト
3. Parameter・スナップショット・ダッキング・カテゴリ
4. ボイス管理・シーケンス種別・通知
