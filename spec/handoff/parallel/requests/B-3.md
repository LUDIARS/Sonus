# B-3: api の検査とテスト（宛先: api の持ち場、本社）

- 出した側: セッション B（段階3 カバレッジ）
- 対象: `api/compose/`（`c_api.cpp` の末尾追記以外）、`api/test/`

## 組②

1. **`snd_config` の末尾に 4 項目を足した**（`max_voice_effects`、`voice_effect_chain`、`voice_effect_bytes`、`voice_effect_settings`。`config.h` の `SND_CONFIG_TOP_S3_VOICE_FX`）。
   - `struct_size` の検査は、足す前の大きさ（384 バイト）の構造体も受けてほしい（短い構造体には既定値）。
   - 注意: `max_voice_effects` はオフセット 380 で、足す前の構造体の**末尾の詰め物の中**に入る。「`struct_size` が項目の終わり以上か」は `sizeof` ではなく `offsetof` + 大きさで判定しないと、古い大きさの構造体から詰め物のごみを読む。
   - 4 項目の範囲の検査（`voice_effect_chain` 0〜4、`voice_effect_bytes` 0〜64 MiB、`voice_effect_settings` 1〜65535。範囲外は `SND_ERR_INVALID_ARGUMENT`）は core の作成時にもあるが、api の `config_check` にも足してほしい。
2. **公開関数 3 つの api 層のテスト**（`snd_set_effect_param`、`snd_set_event_voice_effect`、`snd_set_playback_effect_param`）。B は `c_api.cpp` の末尾に配線しただけで、テストは core 層（`snd::core::System`）で行った。引数の検査（NULL、範囲、ハンドル）と、公開 API からの一巡のテストが無い。

## それまでの代替

core 層のテストで機能は確かめてある。api 層は未検証（報告の「未検証の箇所」に書く）。
