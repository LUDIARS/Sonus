# C-11: 物理マテリアルの強さのカーブの評価と、材質表のライブ反映 — セッション A あて

依頼元: セッション C 組 M（モデル）。

## 何が要るか

1. `PhysCurves`（bank-format.md §6.2: `impulseToVelocity[4]`、`massToPitchCents[2]`、`speedToVolumeDb[2]`）の評価の式。
   ツールのマテリアル表エディタは入力（衝撃量、質量、相対速度）から結果を計算して見せる（9.3「強さの写し方」）。
2. 組の上書き（`PHYS` の pair 表）が接触の種類（impact / slide / roll / break）に関係なく効くかどうか。pair 表は種類の次元を持たない。
3. 足音（footstep）が無い材質のときの代替（ツールは「鳴らない」としている）。

## なぜ要るか

ツールの計算（`tool/include/snd/tool/material_editor.hpp` の `EvaluateStrength` と `Resolve`）をランタイムと一致させるため。
今の physics は stub で、式が無い。

## 欲しい形

- 評価の関数を公開ヘッダか physics の公開の場所に置く（例: `snd::physics::EvaluateStrength(const PhysCurves&, float impulse,
  float massKg, float speed)`）。ツールはそれを呼ぶ（ツールの依存は buildtool / dsp / core / livelink で、physics への依存は
  凍結表の変更になる。式を文書で決めてもらえれば、ツール側で同じ式を実装して比べるテストを書く）。

## それまでの回避（ツールの仮の読み方）

- 衝撃量 < `impulseToVelocity[0]` は鳴らさない、`[1]` 未満は弱、`[2]` 未満は中、以上は強。ベロシティ = 衝撃量 / `[3]`（0..1）。
- ピッチ: 1 kg で `massToPitchCents[0]`、100 kg で `[1]`、その間は質量の常用対数で直線補間（範囲外は端の値）。
- 音量: 0.1 m/s で `speedToVolumeDb[0]`、10 m/s で `[1]`、その間は速度の常用対数で直線補間。
- 組の上書きは全種類に効く。各材質の単体音が無ければ全体の既定（その種類）。同じ Event は 1 回。

## つないでいない箇所

- 材質表の編集のライブ反映（`PHYS` はアプリケーションチャンクのブロブ。差分は ReplaceChunk として `DiffBuilds` に出るが、
  physics が差し替えを受ける口が無い）。A の統合後に組 P がつなぐ。
