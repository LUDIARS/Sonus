# C-12: ランタイムの評価の関数を公開する（カーブ、3D、テンポマップ、ルールの照合） — セッション B（core）と統合担当あて

依頼元: セッション C 組 M（モデル）。急ぎではない（回避済み）。

## 何が要るか

ツールのモデルがランタイムと同じ結果を出すため、次の計算を UI に依存しない公開の関数として置いてほしい。

- カーブの評価（`core/src/core_util.cpp` の `EvaluateCurve`）: 点の配列を受ける形（`float EvaluateCurve(const float* x, const float* y,
  const float* shape, uint32_t count, float at)`）。
- 3D の基本計算（`sys_3d.cpp` の Compute3D の 1 組分と、`sys_dsp.cpp` の距離・コーンの減衰、`sys_render.cpp` の PanFor）。
- 音楽のテンポマップとルールの照合（`music/src/timeline.cpp`、`rules.cpp`）。tool の依存表に music は無いので、music に置いたままでは
  ツールから呼べない（依存表の変更は契約の変更）。

## なぜ要るか

今はツール（`tool/src/curve_editor.cpp`、`spatial_preview.cpp`、`music_editor.cpp`）が同じ式を持ち、ランタイムと比べるテスト
（`tool/test/runtime_compare_test.cpp`: カーブは core の `EvaluateCurve` とビット一致、3D とパラメータの合成は本物の core の出力、
テンポマップは music の `Timeline`、照合は `FindRule`）で一致を確かめている。ランタイムの式が変わるとテストが落ちて気づけるが、
二重に持つより共有の方が安全。

## それまでの回避

上のとおり、同じ式をツールに持ち、比べるテストで守る。
