# A-001: バンク形式 2.1（PHYS の拡張）と buildtool / project-format への追加の依頼

- 依頼元: セッション A（physics）
- 宛先: バンク形式の所有者（契約）、buildtool と project-format（セッション C）
- 状態: 未着手。physics は API で渡す形（`snd_physics_set_table` ほか）で全機能を持ち、PHYS（形式 2.0）からは表せる分だけを読む。

## 1. いまの PHYS（形式 2.0）で表せないもの

physics の API（`physics/include/snd/physics/physics.h`）にあって、PHYS に無いもの:

| 項目 | API | PHYS 2.0 での扱い（physics の読み方） |
| --- | --- | --- |
| ゲームの物理マテリアル → サウンドマテリアルの対応表 | `snd_physics_set_material_map`（`snd_physics_material_entry`） | 無し。読み込んでも対応表は変えない（恒等のまま） |
| 表面パラメータ（対応表の 1 項目あたり最大 4 個の Parameter の ID と値） | 同上 | 無し |
| 接触種別ごとの組の上書き | `snd_physics_table_desc.pair_by_kind[4]` | 種別共通の 1 枚を 4 種別に入れる |
| モーション別の足音 `[N][6]` | `footstep` | 無し（PHYS の足音は「モーション共通」の列として読む） |
| 足音の全体の既定 | `footstep_default` | 無し（0） |
| 点列の区分線形カーブ（5 種類 × 最大 8 点、材質ごと + 表の既定） | `snd_physics_curves` | `PhysCurves`（閾値 4、cents 2、dB 2）を決まった点列に写す（physics.h の「PHYS mapping」） |
| 重み → 音量のカーブ（足音） | `weight_to_volume` | 無し（恒等） |
| 表の衝撃量の閾値 | `impulse_threshold` | 各材質の `impulseToVelocity[0]` の最小値 |
| 相対速度 → 擦れ音のピッチ | `speed_to_pitch` | 無し（1） |

## 2. 配置の案（形式 2.1、minor。古いランタイムは読み飛ばす）

`PhysTable.reserved`（オフセット 56、u64）を `extOffset` にする。0 なら拡張なし（2.0 と同じ）。PHYS の `ChunkEntry.version` を 2 にする。
すべてのオフセットは PHYS チャンク先頭から、4 バイト境界（u64 を含む構造体は 8 バイト境界）。

```
struct PhysTableExt {               // extOffset の先、8 バイト境界
  u32 structBytes;                  // = sizeof(PhysTableExt)。将来の追加は末尾に
  u32 flags;                        // bit0: pairByKind あり
  u64 pairByKindOffset;             // u32 EventID[4][N*N]（flags bit0 のとき。0 = 上書きなし、添字 min*N+max）
  u64 footMotionOffset;             // u32 EventID[N][6]（0 = なし。既存の footstepOffset はモーション共通の列）
  u32 footstepDefault;              // EventID（0 = なし）
  f32 impulseThreshold;             // 表の閾値（N*s、>= 0）。NaN なら「材質の閾値の最小」（2.0 の読み方）
  u64 curvePointsOffset;            // PhysCurvePoints[N]（0 = なし → PhysCurves の写し方）
  u64 defaultCurvePointsOffset;     // PhysCurvePoints（表の既定。0 = なし）
  u64 weightCurveOffset;            // PhysCurve（足音の重み → 音量。0 = 恒等）
  u64 mapOffset;                    // PhysMaterialMapEntry[mapCount]（0 = 対応表なし = 恒等）
  u32 mapCount;                     // ゲームの物理マテリアルの数（番号 0..mapCount-1）
  u32 reserved;
};
struct PhysCurve {                  // 72 B（snd_physics_curve と同じ配置）
  u32 count;                        // 0..8（0 = 未設定）
  u32 reserved;                     // 0
  f32 points[8][2];                 // x, y。x は非減少
};
struct PhysCurvePoints {            // 5 × 72 = 360 B（snd_physics_curves と同じ配置）
  PhysCurve impulseToVolume, impulseToVelocity, massToPitch, speedToVolume, speedToPitch;
};
struct PhysMaterialMapEntry {       // 36 B
  u16 soundMaterial;                // 0xFFFF = 材質不明
  u16 paramCount;                   // 0..4
  struct { u32 id; f32 value; } params[4];  // Parameter ID（snd_hash_id）と値。予約 ID は不可
};
```

`snd_physics_material_entry` と `snd_physics_curve` は上と同じ配置にしてあるので、physics は検査の後そのまま写せる。

検査（buildtool の自己検査と bank_check、physics の読み込みで同じもの）: 範囲・整列・個数、カーブの count <= 8・x 非減少・有限、
`soundMaterial < N` か 0xFFFF、paramCount <= 4、Parameter ID の重複なし。

## 3. project-format（materialTable）への追加の案

```json
{"type": "materialTable", "name": "Phys/Default", "bank": "Level1",
 "materials": ["metal", "wood", "stone"],
 "single": {"metal": {"impact": "SE/Metal", "slide": "SE/MetalSlide"}},
 "pairs": [{"a": "metal", "b": "glass", "event": "SE/MetalGlass"},
           {"a": "metal", "b": "stone", "event": "SE/MetalStoneBreak", "kind": "break"}],
 "footsteps": {"wood": "SE/StepWood",
               "stone": {"any": "SE/StepStone", "run": "SE/RunStone", "land": "SE/LandStone"}},
 "footstepDefault": "SE/StepGeneric",
 "threshold": 0.2,
 "curvePoints": {"metal": {"impulseToVolume": [[0.1, 0.2], [5, 1]], "speedToPitch": [[0, 0.8], [10, 1.2]]},
                 "default": {"massToPitch": [[1, 1.2], [100, 0.7]]}},
 "weightToVolume": [[0, 0], [1, 1]],
 "gameMaterials": [{"id": 0, "sound": "stone"},
                   {"id": 1, "sound": "stone", "params": {"Surface/Wetness": 1}},
                   {"id": 7, "sound": "metal", "params": {"Surface/Rust": 0.3}}]}
```

- `pairs[].kind`（省略 = 全種別）があれば `pairByKind` を出す。
- `footsteps` の値が文字列ならモーション共通の列、オブジェクトなら `any` / `walk` / `run` / `sprint` / `jump` / `land` / `scuff`。
- `curves`（2.0 の 4/2/2 個の数値）と `curvePoints` が両方あれば `curvePoints` が優先。
- `gameMaterials[].id` は 0..65534。抜けた番号は「恒等」（`soundMaterial = id`、id >= N なら 0xFFFF）。`params` の名前は
  parameter オブジェクトの参照（無ければ名前の `snd_hash_id`）。
