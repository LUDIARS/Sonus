# B-4　source への依頼

組④の作業先は `wip/b-g4`。受け入れ前の依頼として、source と契約の担当に次の二点を渡す。

| 対象 | 現在の制約 | 必要な結果 |
| --- | --- | --- |
| 開始要求と有限ループ | core は CLIP.loopCount から終端を決めるが、開始要求に回数を渡す欄がない | source に回数と区間終端を伝え、ピッチが変わる場合と仮想化から戻る場合にも N 周目の終端を共有できること |
| 描画エラーの通知 | core が完了とエラーを区別できる結果がない | source の失敗を描画結果から core に渡し、自然終了と区別して SND_END_ERROR を一度だけ通知すること |

B は source_if.hpp と source/ の所有者にこの変更を依頼する。既存バンクと従来の正常終了時の動作を保つ。

設計 §7「動的生成・入力」の Input、Oscillator、Noise は source / platform 側のソース種別・デバイス接続が必要。core テスト用 Oscillator を製品のソース種別の実装実績には含めない。
