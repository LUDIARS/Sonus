# C-05: 再生で負荷 LOD の段とストールを再現する手段（依頼先: core / セッション B）

## 何が要るか

```cpp
// LiveTap から: 次のブロックからの負荷 LOD の段を固定する（kNoForce で解除）
void LiveForceLod(std::uint32_t level) noexcept;
// LiveTap から: ストリームスロットのストールを 1 回起こしたことにする（2.5 の「ストール無し」を外れた記録の再現）
void LiveInjectStall(std::uint32_t slot) noexcept;
```

## なぜ要るか

記録には LOD の段の変化とストールのブロックが入っている（11.3）。再生でそれを再現すれば、2.5 の条件を外れた記録でも
同じ決定（どのボイスが落ちたか）を確かめられる。

## それまでの回避

再生は再現しない。記録にある LOD の変化・ストールを `kReplayLodRecorded` / `kReplayStallRecorded` で、再生中の
LOD・ストールを `kReplayLodInReplay` / `kReplayStallInReplay` で知らせ、`BitExactExpected()` を false にする。

## つないでいない箇所

再現（`ReplayDesc` に「LOD とストールを再現する」を足すのは手段ができてから）。
