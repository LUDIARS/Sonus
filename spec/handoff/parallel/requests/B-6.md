# B-6　リミットグループに奪われた再生の終了理由（本社承認済み）

`wip/b-g4` の c377047 で `core/test/core_voice_test.cpp` の `CoreVoice.LimitGroupNeverRejectsAndOldestSteals` は、唯一のボイスを奪われた再生に `SND_END_COMPLETED` を期待する。設計 §2.1 と types.h は `SND_END_STOLEN` / `SND_END_DETAIL_LIMIT_GROUP` を定義している。通知を受けるゲームは、現在この終了を自然終了と区別できない。

2026-11-24 に本社がこの既存アサーションと終了理由の変更を承認。実装担当とテスト担当が各自の変更を用意し、同一コミットにまとめる。個々のボイスの終了と再生全体の終了を区別し、残るボイスがある間は再生を継続する。

## 再検証で見つかった同じ期待値

修正後の `10d6b07` では独立テスト 5 実行ファイルと `core_test` が通過した。一方、`core_g4_test` に含まれる次の 7 アサーションも、グループによって最後のボイスを失った再生に COMPLETED を期待して失敗した。行番号は `c377047` の `core/test/core_voice2_test.cpp`。

| ケース（CoreVoice2） | 行 | 対象 |
| --- | --- | --- |
| StealQuietestTakesTheLowestAudibility | 57 | 最小可聴度の被害者 |
| StealQuietestTieTakesTheOldest | 76 | 同順位で最古の被害者 |
| StealQuietestSparesAVoiceOfTheSameBlock | 90 | 新規を残し、前のブロックからいるボイスを奪う |
| StealLowestPriority | 107、115 | 低優先・同優先時の被害者。新規を拒否した場合の REJECTED は別途検査 |
| LimitHierarchyEventThenGroupThenGlobal | 157、158 | グループで最古の 2 再生。Event 上限と再トリガー拒否は別途検査 |

2026-11-24、本社が上記7箇所と、同じ終了原因を持つ既存期待の変更を承認した。テスト担当が各被害者に届く通知の reason と detail の両方を確認する。157、158 行はリミットグループによる奪取なら LIMIT_GROUP、全体上限なら VOICE_LIMIT を期待する。新規要求を拒否する REJECTED の期待と CountOf(...) == 0 は維持する。異なる理由の食い違いは個別の依頼とする。
