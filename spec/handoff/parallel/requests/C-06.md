# C-06: プロファイラ用の読み出し: ストリームの詳細と CPU の内訳（依頼先: core / source / jobs、セッション B）

## 何が要るか

```cpp
struct LiveStreamDetail { std::uint32_t slot, state, playback; Id event; std::uint64_t bufferedFrames, readAheadFrames; std::uint32_t pendingReads, stalls; };
std::uint32_t LiveStreams(LiveStreamDetail* out, std::uint32_t cap) const noexcept;
struct LiveWorkerTiming { std::uint32_t worker; std::uint64_t busyNs; std::uint32_t chunks, lateChunks; };
std::uint32_t LiveWorkers(LiveWorkerTiming* out, std::uint32_t cap) const noexcept;  // 直前のブロック
```

## なぜ要るか

設計書 11.1 のプロファイラ（ストリーム、CPU）。今の core の読み出しはストリームスロットのイベント（`LiveStreamEvent`）と
ブロック全体の時間（`BlockProfile`）だけ。

## それまでの回避

StreamList はスロット、イベント、状態（イベントがあるか）、livelink が数えたストールだけ。BlockDetail はブロック全体の
合計・ロジック・レンダー、描いたボイス、チャンク、遅れたチャンク、保留、並列か、LOD。

## つないでいない箇所

先読みの残り、読み込み中の数、ワーカーごとの時間（StreamInfo / BlockDetail の末尾に足す、minor の追加）。
