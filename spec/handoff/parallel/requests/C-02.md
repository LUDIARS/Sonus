# C-02: 試聴の再生ハンドルを記録の時点で返す（依頼先: core / セッション B）

## 何が要るか

`System::RecordLive(LiveAudition)` が取った Playback のハンドルを呼び手に返す形。例:

```cpp
snd_result RecordLiveAudition(const cmd::LiveAudition& c, snd_playback_handle* out) noexcept;
```

## なぜ要るか

試聴の再生ごとの停止（ツールが 1 つの試聴だけを止める）と、試聴の位置の更新に要る。今はハンドルが core の中で取られて
返らないので、livelink はオーディオスレッドの記録の走査（`LiveTap::arena`）でハンドルを知る。

## それまでの回避

全停止は動く（livelink-protocol.md §8.6）: オーディオスレッドが試聴のハンドルを覚え、全停止の印でライブリンクの
スレッドに渡し、`System::Stop` で止める。試聴ごとの停止は無い。

## つないでいない箇所

試聴ごとの停止のメッセージ（プロトコルに足すのはハンドルが返るようになってから）。
