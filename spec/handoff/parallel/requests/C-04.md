# C-04: 記録の開始時の core の状態を書き出す・読み戻す（依頼先: core / セッション B）

## 何が要るか

オーディオスレッド（LiveTap::block の中）で、core の状態を書き出す読み出しと、再生側で同じ状態を作る入口。

```cpp
// 書き出し（記録の開始ブロックの終わりに一度）
std::uint32_t LivePlaybacks(LivePlaybackState* out, std::uint32_t cap) const noexcept;  // 再生中の Playback（ハンドル、イベント、状態、位置、シード、パラメータ）
std::uint32_t LiveParams(LiveParamState* out, std::uint32_t cap) const noexcept;        // グローバル・エミッタ・再生のパラメータとスイッチの値
std::uint32_t LiveEmitters(...)、LiveTransports(...)、LiveListeners(...)、バス・カテゴリの音量とフェード、スナップショット
// 読み戻し（再生の先行ブロックで）
snd_result LiveRestore(const LiveStateView& state) noexcept;
```

## なぜ要るか

途中から始めた記録（`RecordOrigin::MidRun`）を、記録時と同じ出力で再生するため（設計書 11.3「不具合報告とテストに使う」）。
今は livelink が持つ状態（上書き層のセル、ライブのオーバーライド）だけを書き出している（RecordCell / RecordOverride）。

## それまでの回避

記録の Begin レコードで作成時からか途中からかを区別し、再生は `kReplayMidRun` で知らせる。途中からの記録は、再生する
システムを同じ core の状態にしてから `Start` したときだけ一致する（テストは「作成時から」か、状態を揃えてから再生する）。

## つないでいない箇所

core の状態のレコード種別（記録形式に足すのは読み出しができてから。`kRecordOverride` の後に足す予定）。
