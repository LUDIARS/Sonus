# C-07: 決定のタップ（選ばれた Clip、起きた遷移）（依頼先: core / music、セッション B）

## 何が要るか

`LiveTap` に、ロジックの決定を知らせる呼び口:

```cpp
void (*decision)(void* user, std::uint32_t kind, std::uint32_t playbackSlot, Id what, std::uint32_t detail) noexcept;
// kind: ClipChosen（シーケンス種別の選択、ランダム幅）、TransitionFired（遷移ルール）、StateChanged、VoiceStolen ...
```

## なぜ要るか

設計書 2.5「ロジックの決定（どの Event がいつ鳴り、どの Clip が選ばれ、どの遷移が起きたか）が一致する」を、再生の
決定のログで直接比べるため。

## それまでの回避

`Replayer` の決定のログは、適用した Play / LiveAudition / Stop、再生の終わり、イベントリングのマーカー・拍・エラー・警告、
ボイスの一覧の要約（イベント、スロット、状態、仮想か、バス、ソースの種類）の変化で代える。Clip の選択はボイスの一覧の
変化として間接に現れる。

## つないでいない箇所

Clip と遷移の項目（`ReplayDecision` の kind に足す）。
