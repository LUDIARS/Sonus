# B-7　RTワーカーのチャンク取得試験（jobs 担当・本社）

組②の実装担当は、Release 全件実行で `jobs_rt_claim_steal_test` が1回失敗したと記録した。同時刻に別のビルドが動いていた。担当が再ビルド後に20回繰り返した結果は全件成功だった。最初に失敗した回の生ログは引き継ぎ資料に含まれていない。記録は `B/report-g2-impl.md` の「Release 全件」と `B-handoff.md` §7 にある。

受け入れ担当が組②修正版の新規 Release で実行した全223件では、この実行ファイルも成功した。jobs 担当には、今後再現したときに失敗したアサーションとチャンクの取得順を記録し、ワーカースレッドの起動遅延を許す仕様とテストの前提を照合してほしい。B では jobs のテスト・実装を変更していない。

同じ受け入れ用 Release 実行ファイルを排他で `ctest -j1 --repeat until-fail:20 -R '^jobs_rt_claim_steal_test$'` にかけた。対象の `RtClaimSteal.StalledClaimIsRunByTheCaller` は20/20成功し、報告された失敗は再現しなかった。
