# B-2: バンク形式と buildtool への追加（宛先: bank / buildtool の持ち場、本社）

- 出した側: セッション B（段階3 カバレッジ）
- 対象: `contract/internal/include/snd/format/bank_format.hpp`、`spec/interface/bank-format.md`、`buildtool/`、プロジェクト形式

B は列が無い機能を、公開関数（実行時の設定）で動く形にした。設計ツールで設定してバンクに焼けるようにするには、次の列が要る。

## 組②（D-130〜D-133）

| 何 | 要る列 | 今の代替 |
| --- | --- | --- |
| Event / Track の重いボイスエフェクト | `EVNT`（または `TRAK`）に `voiceEffectFirst` / `voiceEffectCount`（`EFFX` の行を指す） | `snd_set_event_voice_effect`（実行時に Event ごとに設定）。core は枠・設定表・処理まで出来ている。列が来たら、登録時に同じ設定表へ入れるだけ |
| Parameter カーブでエフェクトのパラメータを動かす | `CURV.target = EffectParam` の宛先（どの `EFFX` 行の何番か。例 `CURV.targetRow` / `CURV.targetIndex`） | 無し。`snd_set_effect_param` とスナップショット（組③）だけ |
| 同じ対象バスに `DUCK` kind 0 が複数ある | buildtool の警告（サイドチェーンのキーになるのは最初の 1 本だけ、D-131） | 実行時は最初の 1 本を黙って使う |

## 組③・④の入力データ（未受け入れ）

- CURV の Send にも対象 SEND 行が必要。EffectParam の行・パラメータ番号と同様に宛先の欠落を検出する。旧バンクで任意の先頭行へ誤って適用しない。
- 効果音の素材マーカーは ASST から先頭行・件数で引ける表にし、素材内フレーム位置とマーカー ID を保持する。
- ACTN に SetParam のスコープと ApplySnapshot の遷移時間を追加する。発火時刻 timeMs と値 value は旧バンクと同じ意味を保つ。
- TRAK.flags の定義と許可ビットを明記する。CLIP.loopCount の 0（無限）、1（素材既定）、N ≥ 2（ループ区間 N 周目の終端まで、テールなし）を文書化する。
- レイヤーが 3 枚以上重なる区間をオーサリング時に警告する。等パワーを保証するのは 2 枚の重なりまで。

## 組①のオーサリング列と組③のカーブ列の省略

- 組①の Event 単位のドップラー係数、コーン外ローパス、固定 spread、距離リバーブ送りの専用バスを指定する列を検討する。現在の距離送りは Event の出力バスの最初の SEND の先に送る。範囲音源とゾーンは Emitter のランタイム設定で指定する。
- buildtool の writer は任意列の全行が既定値なら列を省略する。全行で compose=0 を明示したバンクと、従来の省略バンクが同じデータになりうる。新規の出力は作者が選んだ合成演算を保存し、旧バンクは対象別の既定動作を維持できるよう、writer と形式の担当で調整してほしい。

組③の正式受け入れ `90d7d10` で、共有バンクのFXと送りの対応、旧形式Panの加算順、親の受理・拒否をまたぐ遷移を確認した。個別Send／EffectParamの宛先とACTN行の遷移時間を永続化する列はbank／buildtoolへの依頼。
