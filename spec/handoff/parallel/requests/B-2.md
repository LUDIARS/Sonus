# B-2: バンク形式と buildtool への追加（宛先: bank / buildtool の持ち場、本社）

- 出した側: セッション B（段階3 カバレッジ）
- 対象: `contract/internal/include/snd/format/bank_format.hpp`、`spec/interface/bank-format.md`、`buildtool/`、プロジェクト形式

B は列が無い機能を、公開関数（実行時の設定）で動く形にした。設計ツールで設定してバンクに焼けるようにするには、次の列が要る。

## 組②（D-130〜D-133）

| 何 | 要る列 | 今の代替 |
| --- | --- | --- |
| Event / Track の重いボイスエフェクト | `EVNT`（または `TRAK`）に `voiceEffectFirst` / `voiceEffectCount`（`EFFX` の行を指す） | `snd_set_event_voice_effect`（実行時に Event ごとに設定）。core は枠・設定表・処理まで出来ている。列が来たら、登録時に同じ設定表へ入れるだけ |
| Parameter カーブでエフェクトのパラメータを動かす | `CURV.target = EffectParam` の宛先（どの `EFFX` 行の何番か。例 `CURV.targetRow` / `CURV.targetIndex`） | 無し。`snd_set_effect_param` とスナップショット（組③）だけ |
| 同じ対象バスに `DUCK` kind 0 が複数ある | buildtool の警告（サイドチェーンのキーになるのは最初の 1 本だけ、D-131） | 実行時は最初の 1 本を黙って使う |
