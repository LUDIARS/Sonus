# A-002: ハンドルを返す PlayAt（api / core への依頼）

- 依頼元: セッション A（physics）
- 宛先: api（`api/compose/c_api.cpp`）と core の所有者
- 状態: 未着手（physics は回避策で動いている）

## 1. 背景

`snd_play_at(sys, event, position, when)` はハンドルを返さず、Parameter・音量・ピッチを渡せない（D-28）。
physics は Impact / Break の 1 回ごとに Parameter（衝撃量、ベロシティ、個数、相対速度、質量、表面パラメータ）と、
`snd_set_playback_volume` / `snd_set_playback_pitch` を渡すので、いまは

```
snd_create_emitter -> snd_set_transform -> snd_play -> snd_set_param_playback ... -> （後の呼び出しで）snd_destroy_emitter
```

の 5〜12 コマンドと、Emitter のスロットを 1 つ使う。さらに A-004 の欠陥のため、Emitter を同じフレームで破棄できず、
`emitter_hold_seconds`（既定 0.1 秒）のあいだ保持している（Emitter のスロットを予算 × 保持時間ぶん余分に使う）。

## 2. 依頼

1 コマンドで「位置つき・ハンドルあり」の再生を記録する関数:

```c
/* PlayAt that returns the playback handle: the implicit emitter (D-42) is created at `position`
 * and released with the playback. Same errors as snd_play (invalid handle when no playback slot). */
SND_API snd_playback_handle SND_CALL snd_play_at_ex(snd_system* sys, snd_id event,
                                                    const snd_vec3* position, const snd_when* when);
```

- 中身は `snd_play_at` と同じ `cmd::Play`（`kPlayHasPosition`）で、`kPlayOneShot` を立てないだけ（ハンドルを返す）。
- できれば `snd_play_user_buffer_ex` と同じく、開始時の音量・ピッチを同じアリーナに続けて記録する形
  （`snd_play_at_ex2(sys, event, position, volume, pitch, when)`）も。最初のブロックから効く。
- 暗黙の Emitter が無いとき（A-004 の 2）は、無効ハンドルか、終了理由で分かるようにしてほしい。

## 3. physics 側の対応（入ったら）

`PlayPositioned`（`physics/src/physics.cpp`）を `snd_play_at_ex` に置き換え、保持する Emitter の環をやめる。
`emitter_hold_seconds` / `max_held_emitters` は互換のため残して無視するか、版を上げて消す。
