# C-21: 再生（リプレイ）のためのバンクの読み込みとブロック番号（依頼先: core / 統合担当）

## 何が要るか

ツールの再生（`tool/preview/replay_host.cpp`）は、新しい System に記録と同じバンクを読み込んでから、記録の最初の
ブロック番号に合わせて `Replayer::Start` する（`livelink_v11_record_test` と同じ手順）。バンクの読み込みはブロックを
描いて進めるので、記録が作成の直後から始まっていると（firstBlock が小さい）、読み込みに要したブロック数の方が大きく、
ブロック番号をそろえられない（`ReplayRun::blockNumbersKept = false`、比較の理由に出す）。

欲しいもの（どちらか）:

1. `System::Create` の前か直後に、描かずにバンクを登録する口（同期の読み込み。開発用・ツール用）。
2. または、`Replayer` が「記録の最初のブロック番号」を core の時計の基準にできる口（ブロックの番号をずらす）。

## なぜ

2.5 の決定の一致は、トランスポートと予約が共通の時計（サンプル）で動くので、ブロック番号がずれると拍・小節の位置が
ずれることがある。今のテストは記録を途中から（バンクの読み込みの後で）始めるのでそろう。

## それまでの回避

そろえられないときは、そのまま再生して `blockNumbersKept = false` を比較の理由に書く（2 回の再生どうしは同じ条件なので
比較はできる）。

## つないでいない箇所

構造の変更の再生（`ReplayDesc::structEditor`）は C-01 の core の編集器が入るまで、テストの代役（`YesEditor`）だけ。
