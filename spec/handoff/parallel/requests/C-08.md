# C-08: ツールが使う livelink 1.1 の API（依頼先: 組 P / tool）

`tool/` は変更していない。ツール側の対応は組 P がやる。使う API（`livelink/include/snd/livelink/client.hpp`）:

- 照合: `ClientDesc::deferSyncDecision = true` → BuildMismatch で Handshake のまま止まる（`AwaitingSync()`）。
  `QueryBanks()` → `CopyBanks()` でバンクごとの（bankId、言語、projectBuildHash、contentHash、writable）を見て、
  `DecideSync(SyncMode::SendDiffs)` か `Disconnect`。差分は `SetValue` / `ReplaceChunk`、作り直しは `ReloadBank`。
  `tool/src/connection.cpp` の `switch (ClientState)` は変わらない（新しい状態は足していない）。
- 版: `PeerMinor()`、`Supports(MessageType)`。1.0 のゲームには 1.1 の送信関数が 0 を返す。
- 項目単位の Revert: `RevertValue(SetValue の宛先)`。読み返し: `ReadCell` → `TakeCell` / `WaitCell`（`CellValue`）。
  `tool/src/cell_sync.cpp` の同期に使える（上書き中か、バンクの値）。
- 試聴の全停止: `StopAuditions()`。
- 構造の変更: `StructEdit`。SND_ERR_OUT_OF_BUDGET / SND_ERR_UNSUPPORTED なら再ビルドと `ReloadBank`。
  SND_ERR_LIMIT_REACHED は戻しの記録か差し替えの枠が一杯（D-172）。ライブで足したバスを外すと、その上のライブのエフェクトと
  センドも一緒に外れる（ツールのモデルでも一緒に消す）。
- ホットリロード: `ReloadBank(bankId, languageId, path)`、途中経過 `CopyReloadStatus`。ファイルが別のバンクなら Failed
  （SND_ERR_INVALID_ARGUMENT）で、要求したバンクは外れたまま（D-173）。
- 保持数（D-170）: Ack 1024、CellValue 256 など（`client.hpp` の `kClient*`）。取りこぼしは `ClientStats` の `*Lost`。
  たくさんの ReadCell を投げるときは 256 件以内に `TakeCell` する。
- Server は 1 つの `LiveRuntime` に 1 つだけ Start できる（D-170）。
- プロファイラ: マスク `kProfStreamList`、`kProfBlockDetail` → `CopyStreams`、`CopyBlockDetails`。
- 更新番号: `Sequences()`、`CopyTimingsSince` / `CopyEventLogSince` / `CopyStallsSince` / `CopyLodsSince` /
  `CopyBlockDetailsSince` / `CopyMeterHistorySince`。
- 記録: `RecordReader` は 1.1 のレコード（`ll::IsKind(item, ll::kRecordBegin)` など）を返す。`tool/src/recording_file.cpp`
  の `switch (item.kind)` は 1.1 の種別を数えない（警告は出ない。数えるなら `IsKind` で）。
- 再生: `ReplayInfo` の `origin`、`conditions`、`leadBlocks`、`Replayer::BitExactExpected()`（再生どうしのビット一致）と
  `ReproducesRecordedRun()`（記録した実行との一致、D-175）、`CopyDecisions`、`OutputDigest`。`leadBlocks` が 1 のときは、
  記録の最初のブロックより 1 ブロック前に `Start` する。`Finished()` は `Blocks()` 個描いた直後に true（D-175）。
