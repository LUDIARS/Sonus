## 組②の受け入れレビュー

差し戻し 192bace では recorder が SetSwitch と後続 SetParam を記録する前にバイト数を確認する。voice_fx の Acquire は枠の再取得時に種別と値を同じ Event 設定から読み、fresh のときは始点・終点をそろえる。バスの適用経路と Playback の設定経路は標準エフェクトの初期化専用パラメータを判別する。b527335 は Echo/Delay 初期化時に動作レートで上限を保持し、リング容量との小さい方を使う。9e7b36e は独立テストの未使用定数 2 個を削除した。

**差し戻し**　`core/src/voice_fx.cpp` の Acquire は、プラグインが返す `uint32_t` の状態サイズを 64 バイト境界に丸めてから、枠に収まるか検査する。加算が 32 ビットの表現範囲を超えると過小評価される。実装担当は丸めと残容量の比較を十分広い型で行い、枠を超える要求を初期化前に D-133 の経路へ返すこと。独立テスト担当は、大きなメモリを確保・書き込みせずに、予算外の要求では初期化を呼ばず dry と警告になることを確認する。これはコードレビュー所見。該当ケースの実行、修正、独立テストは未了。

## 組④の判定

- 4.1 の 2 件を差し戻す。アクションだけの Event は最後のアクションが適用されるまで存続する。Stop 後は残りを適用しない。一時停止と再開を交互に繰り返しても再開ブロックで期限が来たアクションを取り消し続けない。操作種別ごとの適用タイミングは D-145 案に従う。
- 3 枚以上のレイヤーの等パワーは保証範囲外とする案を維持。親のピッチ・素材ループにトラック時刻は従属させず、Playback の一時停止で止め、各アクションは一度発火する方針。再スタート時のフェードは再生経過時間基準（D-146 案）で再確認する。
- リミットグループで奪われた再生の COMPLETED → STOLEN / LIMIT_GROUP は本社承認済み（B-6）。実装担当・独立テスト担当を分けて修正中。D-140〜148 は受け入れ完了後に確定する。組① D-150〜159、組③ D-160〜169 は未確定。
