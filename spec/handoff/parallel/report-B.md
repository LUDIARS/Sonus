## 組②の受け入れレビュー

差し戻し 192bace では recorder が SetSwitch と後続 SetParam を記録する前にバイト数を確認する。voice_fx の Acquire は枠の再取得時に種別と値を同じ Event 設定から読み、fresh のときは始点・終点をそろえる。バスの適用経路と Playback の設定経路は標準エフェクトの初期化専用パラメータを判別する。b527335 は Echo/Delay 初期化時に動作レートで上限を保持し、リング容量との小さい方を使う。9e7b36e は独立テストの未使用定数 2 個を削除した。

**差し戻し**　`core/src/voice_fx.cpp` の Acquire は、プラグインが返す `uint32_t` の状態サイズを 64 バイト境界に丸めてから、枠に収まるか検査する。加算が 32 ビットの表現範囲を超えると過小評価される。実装担当は丸めと残容量の比較を十分広い型で行い、枠を超える要求を初期化前に D-133 の経路へ返すこと。独立テスト担当は、大きなメモリを確保・書き込みせずに、予算外の要求では初期化を呼ばず dry と警告になることを確認する。修正は wip/b-g2。Acquire は要求を uint64_t に広げて AlignUp64 で丸め、残容量との比較を通過した場合だけ縮小する。InitVoiceFx の枠数×バイト数も CheckedMul を通す。独立テストは 128 / 129 バイトと二段の全体拒否、警告対象、枠の再利用を観測する。32 ビットの表現境界は静的確認。
